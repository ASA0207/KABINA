KABINA of Hirune — GitHub Pages 배포

1. GitHub에서 새 공개 저장소 생성 (예: kabina-portfolio)
2. 이 ZIP의 index.html 파일을 저장소 최상위에 업로드
3. Settings > Pages > Build and deployment > Deploy from a branch
4. Branch: main / (root) 선택 후 Save
5. 수 분 후 GitHub Pages 주소에서 확인

기능: 입장 화면, 반응형 디자인, 우주/오브 애니메이션, 스크롤 등장, 신청 체크리스트 복사, ASA 비밀 이스터에그(키보드로 asa 입력), 상단 이동, 크레페 신청 연결.

주의: 실제 작품 이미지가 제공되지 않아 포트폴리오 영역은 명확히 콘셉트 카드로 표기했습니다. 원본 공지 문구는 저해상도 이미지에서 옮긴 것이므로 게시 전에 작가님에게 최종 확인을 받으세요.
